The proposed AWS update reuses the existing exact-key Lambda role and invoke-only operator policy. It temporarily enables the key, sets private function concurrency to one and replaces the fixed challenge digest with exactly the approved deployment digest. The function still accepts only an empty object and cannot choose another payload. It returns a public signature; no private key is exported. No public endpoint, generic signing API, new role/key, mainnet request or reserve withdrawal is included. IAM does not understand the digest: the pinned function code and local transaction validation are the additional boundaries. Administrators retain their existing ability to change code/policies.

Action-time approval must cover the changed signing authority, one Base Sepolia test contract transaction, the proposed test governance parameters, and up to USD0.10 additional metered AWS verification costs. Do not apply before approval. After an approved fixed signature, independently verify key, signature and payload, run submit-sepolia-timelock.ts without its broadcast flag for preflight, then submit only the approved Base Sepolia transaction. Check successful receipt, deployed code, constructor immutables and role membership. Disable the key and pause the function regardless of outcome. A submission timeout is ambiguous: reconcile the deterministic signed transaction hash before any retry; never invent a new nonce to retry.

The existing paused protected-signing-qualification.json is the cleanup target. It also restores the non-monetary challenge handler while preserving the disabled key and zero concurrency. Contract deployment and successful faucet funding do not qualify customer financial operations, production contracts or reserve backing.

Commands require owner-controlled local files. TypeScript strict checks cover both deployment commands. No private credentials enter this repository. The public RPC is used for qualification diagnostics only; production needs the previously selected dedicated providers and durable protected credential handling.
