# Architecture gaps — initial assessment

Legacy database pricing and wallet integrations do not establish the required Base contract settlement authority. Required new seams include exact monetary execution, governed vault and asset registry, deterministic settlement, double-entry accounting, durable inbox/outbox processing, chain finality and reorganization processing, reconciliation, independently authorized recovery, and release activation controls.

Passkeys, smart accounts, transaction-bound authorization, compliance eligibility, merchant controls, developer APIs, applications, and production infrastructure require source-level assessment and implementation evidence. They are not marked absent solely because an initial file listing did not show them. No production readiness claim is supported.
